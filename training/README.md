# training/ — archived (dead)

This folder belongs to the **LLM learning program**, which is closed. It is kept as a record
of the experiment, not as working code.

- `split-data.js`, `eval-agreement.py` — the distillation pipeline's data splitter and
  agreement eval (experiment E12). Not maintained.
- The generated artifacts that used to sit beside them — `adapters/` (LoRA weights),
  `data/`, `pilot-split/`, the `.venv` — are git-ignored and can be deleted locally.

What was learned is written up in [`docs/LLM_LEARNING_EXPERIMENTS.md`](../docs/LLM_LEARNING_EXPERIMENTS.md).
Why the program was retired, and what replaced it (the planner playtest bot), is in
[`docs/CPU_PLAYTEST_AUDIT.md`](../docs/CPU_PLAYTEST_AUDIT.md).
